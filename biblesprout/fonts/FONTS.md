# Noto Serif

`res/font/noto_serif_regular.ttf`, `noto_serif_bold.ttf`, `noto_serif_italic.ttf` and
`noto_serif.xml` (the `<font-family>` combining them) are Notesprout SN's copies of Google's
Noto Serif, under the SIL Open Font License 1.1 (https://openfontlicense.org). This note lives
beside `res/`, never inside `res/font/`: a file that is not a font there breaks the resource merger.
