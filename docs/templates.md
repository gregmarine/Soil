# The paper library

Soil keeps the templates: Blank, Default and the three built-in papers are sentinels, never
rows; a static template is a picture the library keeps, with the fit it is laid onto a page
with. `:paper` holds what both sides draw with: the 8 mm geometry, the built-in renders, the
fit arithmetic, the token digest, page-sized rendering, the reuse-before-mint rule, the name
rules and the fuzzy ranking.

## The screen

Templates, reached from Settings: folders, sort, rename, move, duplicate, Fit, pin, import of a
PNG, JPEG or WebP through Soil's own browser over this device (`files.md`; the system picker
while All files access is off) or, with the cloud extension installed, from the provider
(*Import from* asked first, `cloud.md`) under the seam's 16 MiB cap, PNG export at this device's
page size into a folder of this device or under the provider's `Exports/` (*Export to* asked
first), and the Pinned, Recents and Search shelves. Cards are true miniatures, rendered off
Main and cached. The Default folder is reserved: nothing of the person's lands in it.

Started by a Sprout app for a result (`ACTION_PICK_TEMPLATE`, behind the seam permission), the
same browser is the picker: a tap on a paper card answers a `TemplatePick`, never pixels, and
the app does the write. `ACTION_SAVE_TEMPLATE` names and files a picture the app parked through
`stageTemplate`.

## In the notebook

A page's paper is drawn by the app from `template` and `templateImage`; the page sheet's Page
template turns a pick into a reused or minted template row, one undo step; Save as template
rasters the page as it exports, capped, then opens Soil's screen. A folder's default template
is what New notebook starts on (`items.md`).

A calendar page copied to the clipboard carries its grid as a `template` row, a picture under
the image token at the page's size, so the notebook that pastes it reuses the row by bytes and
the same month twice mints one (`clipboard.md`, `calsprout.md`).

## In the sketchbook

A sketchbook's paper is the same library's, picked at New sketchbook and from its page sheet's
Page template, kept as a `template` row and drawn under the rasters — on the screen as part of
g-paper's sheet, never as its template (`sketchsprout.md`), and under the export and the cover.
